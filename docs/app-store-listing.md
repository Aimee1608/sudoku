## App 描述（4000 字符内）

```
彩虹数独是一本装进手机的数独练习册，4×4、6×6、9×9 三种尺寸各成一册，孩子和大人都能找到合适的那一档。

没有广告打断，没有内购弹窗，不需要注册登录，不用连网，也不收集任何个人信息——打开就能做题。

【三种尺寸，各成一册】
· 4×4 入门：每行每列每个小方块放 1 到 4，认得数字就能玩，是孩子理解数独规则的第一步
· 6×6 进阶：2×3 的小方块，从入门过渡到标准盘的中间一站
· 9×9 经典：入门 / 简单 / 中等 / 困难四档，四百多道题按难度从易到难排好

【全部题目一开始就是开着的】
不用解锁，不用等体力，不用看广告换关卡。做到第几题、用了多久、错在哪、连续做了几天，全部记在你自己的设备上。

【题目是算出来的，不是抄来的】
每一道题都保证只有唯一解，难度由程序模拟人类解题过程判定——用到「唯一候选」还是要用上「区块摒除」「数对」「矩形对角线」，决定了它属于哪一档。所以同样二十几个提示数的题，难度可以差很远。

【卡住了有人帮你想】
提示不是直接甩答案，而是告诉你下一格该怎么推：这一行为什么只有这里能放 7，这一宫的 3 为什么只可能在这一列。9×9 讲的是技巧，4×4 和 6×6 会换成问句，引导孩子自己想出来。真想看答案也随时能看，看了不会清空你的记录。

【十五套配色，随时换】
海洋泡泡、蓝莓牛奶、草莓牛奶、积木彩虹、纸与铅笔、复古纸黄、晨曦玫瑰、摩卡拿铁八套浅色，深海探险、星空夜航、摩卡糖果、北欧极光、德古拉、复古暗调、东京夜色七套深色。换的是整套——底色、格线、高亮、数字颜色，连字体形状和圆角都跟着走。还可以让它跟着系统白天黑夜自动切换。

【为孩子准备的开关】
打开「彩色数字」，1 永远是红、5 永远是青，还不熟悉字形的孩子可以靠颜色认位置。这是独立开关，十五套配色都能开。

【做题时该有的都有】
· 笔记：不确定填几时先记下候选小字，正式填入后同行同列的这条笔记会自动清掉
· 撤销、擦除、计时
· 选中格所在的行列宫会淡淡高亮，盘面上相同的数字也会一起亮
· 填错立刻标红，不用做到最后才发现
· 中途退出自动存档，下次打开接着做
· 完整适配 iPad

【关于隐私】
这款 App 完全离线运行，没有服务器，不联网，不含任何第三方广告或分析代码。题库打包在 App 内，你的做题记录和外观偏好只保存在自己设备上。
```
